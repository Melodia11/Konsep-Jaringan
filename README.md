## Daftar Tugas

Repositori ini memuat dokumentasi, analisis, kode program, dan perhitungan untuk tugas mata kuliah Konsep Jaringan:

| No | Folder Tugas | Topik Penugasan | Ringkasan Materi |
|:---:|:---|:---|:---|
| **01** | [`Tugas-01-Pengantar-Konsep-Jaringan/`](./Tugas-01-Pengantar-Konsep-Jaringan) | Pengantar Konsep Jaringan & Standar Wi-Fi | Tugas Bab 1 (Level A & B), kategori kabel UTP (Cat 1-9), standar IEEE 802.11a/b/g/n/ac/ax/be, garis waktu internet, interpretasi metrik Fast.com. |
| **02** | [`Tugas-02-Model-OSI-dan-TCPIP/`](./Tugas-02-Model-OSI-dan-TCPIP) | Model Referensi OSI & TCP/IP | Pembahasan komprehensif Bab 2: Level A (Ingatan & Pemahaman), Level B (Penerapan & Analisis), dan Level C (Evaluasi & Sintesis) — total 30 soal. |
| **03** | [`Tugas-03-Visualisasi-Harmonisa/`](./Tugas-03-Visualisasi-Harmonisa) | Visualisasi Harmonisa Fourier | Skrip Python interaktif (`fourier_synthesis.py`) menggunakan Matplotlib untuk simulasi deret Fourier gelombang kotak dengan harmonisa ganjil ($n=1, 3, 5, 7, 9$). |
| **04** | [`Tugas-04-Perhitungan-Subnetting/`](./Tugas-04-Perhitungan-Subnetting) | Subnetting IPv4 & FLSM | Perhitungan pembagian subnet sama besar (*Fixed Length Subnet Mask*), penentuan prefix, subnet mask, usable host range, dan broadcast address. |
| **05** | [`Tugas-05-Analisis-Traceroute-TTL/`](./Tugas-05-Analisis-Traceroute-TTL) | Analisis Traceroute & Mekanisme TTL | Analisis mendalam cara kerja Traceroute/Tracert, dekrementasi field TTL, pesan ICMP Time Exceeded (Type 11 Code 0), serta anomali probe `* * *`. |
| **06** | [`Tugas-06-Perancangan-VLSM/`](./Tugas-06-Perancangan-VLSM) | Perancangan VLSM `10.252.108.0/24` | Alokasi subnet hemat alamat berdasarkan urutan kebutuhan: Lab A (90 host), Lab B (60 host), Administrasi (14 host), dan End-point P2P (2 host). |
